# Windows 11 Theme for Omarchy

## Description
This theme provides a modern Windows 11 inspired look and feel for Omarchy.

## Features
- Rounded corners (8px)
- Transparent/blur effects where applicable 
- Taskbar positioned at bottom
- Modern typography and spacing
- Windows 11 style colors (dark with accent colors)

## Configuration Details

This theme modifies:
1. Waybar styling for Windows 11 look and feel
2. Hyprland window decorations for rounded corners
3. General theme appearance

## Usage
To apply this theme, use the command:
`omarchy theme set windows-11`
